# Future Feature Ideas

## Concept Map
Interactive visual web showing how topics and concepts connect to each other. Nodes light up as you learn them. Shows relationships like "Linear Algebra -> Machine Learning", "Calculus -> Differential Geometry". Helps users see the big picture of how mathematics fits together.

## Discovery Mode
Inquiry-based learning where instead of teaching then quizzing, you drop the user into a pattern and have them figure out the rule themselves. "Here's 2, 3, 5, 7, 11... what's the pattern? Now predict the next 3." Builds intuition before formal definitions.

## "What If?" Playground
Interactive sliders that let you break math. "What if pi was 4? What happens to circles?" "What if you divide by zero in this equation?" Visual, explorative, memorable. Builds deep understanding through experimentation.

## Math Lore
Unlockable stories behind theorems and mathematicians. The drama of Galois writing proofs the night before his fatal duel. Ramanujan's letters to Hardy. Godel starving himself. Emmy Noether defying the establishment. Gripping human stories that make abstract math feel alive.

## Speed Runs
Timed challenge chains. Solve 10 problems as fast as possible, ranked on a leaderboard. Different categories by topic. Personal best tracking. Competitive, replayable, addictive. Could have weekly rotating challenges.
