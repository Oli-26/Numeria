## Flagged (not edited)

- ling-phonetics / ling-phon-05-c3 + q23: "spelling froze around Chaucer's pronunciation" and "spelling had stabilized earlier with the printing press". Printing reached England in 1476, after the shift began; standardisation overlapped the shift. This is a standard simplification, so I left it.
- ling-phonetics / ling-phon-03-c2 + q13: "French always stresses the final syllable". French stress falls at the end of the phrase, not on each word. This is a conventional teaching approximation.
- ling-morphology / ling-morph-01-c3: infixes called "common in ... Arabic". Arabic infixation is limited (for example Form VIII -t-), and root-and-pattern is the better description.
- ling-syntax / ling-syn-05-c2: "Double nominative constructions in Japanese ('As for elephants, noses are long')". The gloss matches zō wa hana ga nagai (topic plus nominative). The true double nominative is zō ga hana ga nagai.
- ling-semantics / ling-sem-05-c2: compositionality called "Frege's principle". The attribution is conventional but disputed, since Frege's texts stress the context principle.
- ling-historical / ling-hist-05-c1: Ubykh "84 consonants". Sources give 80 to 84.
- ling-historical / ling-hist-q22: the prompt says Hebrew was revived "in the 20th century", but the lesson says the late 19th century. The revival spans both, so this is a minor inconsistency.
- ling-sociolinguistics / ling-soc-03-c3: Fishman's extended diglossia is illustrated with Puerto Rico Spanish/English. Fishman's classic case is Paraguay (Spanish/Guaraní).
