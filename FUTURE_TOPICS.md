### Math

**calculus**
- Advanced Integration Techniques — special functions and integral transforms
- Calculus of Variations — finding functions that optimize quantities
- Differential Forms — exterior calculus, applications in geometry/physics

**linear-algebra**
- Tensor Algebra — tensors and their applications in physics/engineering
- Sparse Matrices — efficient storage and computation
- Matrix Decompositions — QR, LU, Cholesky beyond SVD

**topology**
- Algebraic Topology Deep Dive — homology and cohomology groups
- Differentiable Manifolds — beyond smooth manifolds intro
- Fiber Bundles — principal bundles, vector bundles

**number-theory**
- Elliptic Curves — arithmetic and applications (cryptography deep)
- Analytic Methods — complex analysis applied to NT problems
- Algebraic Number Theory — number fields, rings of integers

**probability**
- Stochastic Processes Deep — Poisson processes, Brownian motion
- Bayesian Networks — graphical models for probabilistic relationships
- Randomized Algorithms — algorithms using randomness to solve problems

**group-theory**
- Representation Theory of Finite Groups — group reps via matrices
- Group Cohomology — cohomology and its applications
- Infinite Groups — free groups, Cayley graphs, geometric group theory

**graph-theory**
- Graph Coloring Algorithms — efficient algorithms for chromatic problems
- Graph Isomorphism — methods to determine isomorphism, Babai's result
- Planar Graphs — Kuratowski, four-color theorem proof sketch

**differential-geometry**
- General Relativity Deep — geometry of spacetime
- Symplectic Geometry — phase spaces in classical mechanics
- Geometric Flows — Ricci flow, Perelman, mean curvature

**set-theory**
- Forcing — Cohen's method and independence results
- Large Cardinals — large cardinal axioms and consistency hierarchy
- Set-Theoretic Topology — topology under set-theoretic assumptions

**fractals**
- Fractal Dimensions — Hausdorff, box-counting dimensions
- Iterated Function Systems — fractals via IFS, attractors
- Fractals in Nature — coastlines, vasculature, lungs

**fourier-analysis**
- Wavelet Analysis — multiresolution analysis, applications
- Time-Frequency Analysis — STFT, spectrograms, Heisenberg
- Sampling Theory — Nyquist-Shannon, aliasing, applications

**complex-analysis**
- Riemann Zeta Function — zeros, prime counting, the Riemann hypothesis
- Complex Dynamics — iteration of holomorphic functions
- Elliptic Functions — Weierstrass, modular forms intro

**computation**
- Quantum Computing Algorithms — Shor, Grover from CS angle
- Formal Verification — Coq/Lean, software correctness
- Computable Analysis — computability over the reals

**philosophy-of-math**
- Constructivism — intuitionist mathematics, Bishop's program
- Structuralism — math as structure, Shapiro
- Mathematical Pluralism — multiple foundations, multiverse view

**combinatorics**
- Ramsey Theory — order from chaos in large structures
- Probabilistic Method — Erdős's nonconstructive existence proofs
- Algebraic Combinatorics — Young tableaux, symmetric functions

**differential-equations**
- Sturm-Liouville Theory — eigenvalue problems
- Boundary Value Problems — Green's functions, methods
- Delay Differential Equations — equations with time lags
